# 物理教科书知识库索引

## 概述

本知识库包含 **7 本教科书**：
- **4 本《新概念物理教程》系列**（赵凯华等著，高等教育出版社）— 基础物理
- **3 本高等教科书**（Ahlfors、Di Francesco、Andrews 等）— 研究级理论物理

所有教科书均已进行语义分块，可通过 RAG 系统检索。基础物理教科书已中英双语化，高等教科书为英文原版。

## 使用指南

### 何时主动查询

**强烈建议在以下情况下主动查询知识库**：

1. **不确定公式的准确形式** — 不要凭记忆，直接查询标准表达式
2. **不确定适用条件** — 很多公式有特定的适用范围（如线性介质、小角度近似等）
3. **符号定义模糊** — 不同教材对同一物理量的符号可能不同（如 D 和 E 的关系）
4. **推导中间步骤卡住** — 查询相关定理或恒等式
5. **需要验证物理直觉** — 用教科书中的标准结论验证自己的推导方向

### 查询语法

```bash
# 基本查询（返回最相关的 5 个片段）
source {project_root}/textbook/rag_env/bin/activate && python3 {workspace}/query_rag.py "查询内容" --top_k 5

# 返回 JSON 格式（便于解析）
source {project_root}/textbook/rag_env/bin/activate && python3 {workspace}/query_rag.py "查询内容" --json

# 调整返回条数
source {project_root}/textbook/rag_env/bin/activate && python3 {workspace}/query_rag.py "查询内容" --top_k 3
```

### 查询技巧

1. **用中文或英文均可** — 知识库已双语化
2. **查询关键概念而非完整句子** — 如"麦克斯韦方程组 微分形式"而非"麦克斯韦方程组的微分形式是什么"
3. **包含关键术语** — 如"电位移矢量 D"、"退极化场"、"安培环路定理"
4. **尝试同义词** — 如果第一次查询不理想，换用相关术语重试
5. **查询公式时带上上下文** — 如"谐振子 能量"比单纯"能量"更精准

### 不适用场景

本知识库覆盖**本科基础物理**（4 本新概念物理教程）和**高等理论物理**（复分析、共形场论、特殊函数），对于以下前沿领域仍需额外的专业参考：

- 弦论和 M 理论
- 量子引力（圈量子引力等）
- 超对称规范理论（N=4 SYM 的高级计算）
- AdS/CFT 对应
- 拓扑量子场论
- 格点规范理论

这些领域需要更专业的研究文献和教材。
