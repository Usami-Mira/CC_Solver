# Standard — 直接求解

## 核心思想

"我知道怎么做，按步骤来就行。"

这是最简单直接的流程：
1. 分析问题，制定计划
2. 执行计划，求解问题
3. 审查结果，确保正确
4. 如果审查发现问题，修正一次

就像做考试题：
- 先审题，想清楚怎么做
- 然后一步步计算
- 最后检查一下答案
- 如果发现错误，改正

---

## 流程图

```
第一步：规划（Planner）
─────────────────────────────────
分析题目：
  • 这是什么类型的问题？
  • 涉及哪些物理定律？
  • 应该用什么方法求解？

输出：解题计划
  • 物理情景分析
  • 适用定律
  • 解题路线


第二步：执行（Builder）
─────────────────────────────────
基于计划，执行完整推导：
  • 写出公式
  • 代入数值
  • 逐步计算
  • 得出答案

输出：完整解答过程


第三步：审查（Evaluator）
─────────────────────────────────
检查解答的正确性：
  • 物理是否正确？（定律用对了吗？）
  • 数学是否正确？（推导有错吗？）
  • 量纲是否一致？
  • 极限情况是否合理？

输出：审查意见
  • PASS：没问题，通过
  • REVISE：有问题，需要修正


第四步：修正（如需要）
─────────────────────────────────
如果审查说 REVISE：
  • 根据审查意见修正解答
  • 重新审查

最多修正 1 次，避免无限循环
```

---

## 关键概念

### 规划（Planning）

不是直接开始计算，而是**先想清楚怎么做**。

好的规划包含：
- **物理分析：** 这是什么问题？涉及哪些物理过程？
- **方法选择：** 用什么定律？为什么用这个而不是那个？
- **解题路线：** 第一步做什么，第二步做什么...

### 执行（Building）

基于计划，**完整推导**。

要求：
- 每一步都写清楚（不跳步）
- 每个公式都注明物理定律
- 每个数值都带单位
- 最终答案醒目标注

### 审查（Evaluation）

独立检查解答的正确性。

检查维度：
- **物理正确性：** 定律用对了吗？假设合理吗？
- **数学正确性：** 推导有错吗？计算有错吗？
- **量纲一致性：** 公式两边的单位一致吗？
- **极限情况：** 参数趋于 0 或 ∞ 时，结果合理吗？
- **守恒律：** 能量、动量、电荷守恒吗？

### 修正（Revision）

根据审查意见，**有针对性地修正**。

不是重做一遍，而是：
- 定位审查指出的问题
- 只修正有问题的部分
- 保持其他部分不变

---

## 关键决策点

### 决策 1：审查发现问题，修正几次？

**最多 1 次。**

理由：
- 如果 1 次修正还不对，说明问题理解有误
- 继续修正可能陷入死循环
- 应该重新规划，或者升级到更复杂的 Pipeline

### 决策 2：什么时候用 Standard，什么时候升级？

**用 Standard：**
- 问题有明确的解法
- 你对方法有信心
- 时间或资源有限

**升级到 Parallel / Iterative / Tree Search：**
- 问题有多种解法，想比较（→ Parallel）
- 不确定方法是否正确（→ Iterative）
- 完全不知道怎么做（→ Tree Search）

---

## 什么时候用 Standard

✅ **适合的场景：**
- 标准竞赛题（有明确解法）
- 教科书例题（方法已知）
- 简单计算题（不需要探索）
- 时间紧迫（最快的流程）

❌ **不适合的场景：**
- 开放性问题（没有标准答案）
- 有多种解法想比较（用 Parallel）
- 需要实验验证（用 Iterative）
- 完全未知的问题（用 Tree Search）

## 实际例子

**问题：** 质量为 m 的物体从高度 h 自由下落，求落地速度。

**规划（Planner）：**
```
这是一个简单的力学问题。

物理分析：
- 自由下落，只受重力
- 初速度为 0
- 下落高度 h

方法选择：
- 用能量守恒：mgh = ½mv²
- 或者用运动学：v² = u² + 2as

解题路线：
1. 写出能量守恒方程
2. 解出 v
3. 代入数值
```

**执行（Builder）：**
```
根据能量守恒：

初始能量：E_i = mgh（势能）+ 0（动能）
末态能量：E_f = 0（势能）+ ½mv²（动能）

能量守恒：E_i = E_f
  mgh = ½mv²
  
解出 v：
  v² = 2gh
  v = √(2gh)

代入数值（假设 h = 10 m, g = 9.8 m/s²）：
  v = √(2 × 9.8 × 10)
  v = √196
  v = 14 m/s

答案：落地速度为 14 m/s
```

**审查（Evaluator）：**
```
检查：
✓ 物理正确：能量守恒适用
✓ 数学正确：推导无误
✓ 量纲一致：[v] = m/s ✓
✓ 极限情况：h → 0 时 v → 0 ✓
✓ 守恒律：能量守恒 ✓

判断：PASS
```

**结果：** 审查通过，无需修正。

## 核心优势

1. **简单直接** — 流程清晰，易于理解
2. **快速高效** — 最少的步骤
3. **资源节省** — 只需要 3 个 Agent
4. **适合大多数问题** — 标准题都能解决

## 主要局限

1. **只有一条路** — 如果方法错了，只能修正 1 次
2. **无法探索** — 不能尝试多种解法
3. **不适合开放问题** — 需要事先知道怎么做
