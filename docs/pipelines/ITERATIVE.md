# Iterative — 迭代探索

## 核心思想

"我不知道答案，但我知道怎么一步步逼近它。"

面对开放性问题时，不要期望一次就做对。而是：
- 先做个粗略的尝试
- 看看结果怎么样
- 根据反馈调整方向
- 重复，直到满意

这就像科学研究的过程：假设 → 实验 → 分析 → 修正假设 → 再实验...

---

## 流程图

```
循环开始
    ↓
提出假设
  "我觉得这个问题可能是..."
  "我猜测系统应该满足..."
    ↓
设计实验
  "如果我假设是对的，那么应该观察到..."
  "我可以通过...来验证"
    ↓
执行实验
  数值模拟、理论推导、量级估算...
    ↓
评估结果
  "实验结果和我的假设一致吗？"
    ↓
判断方向
  ├── 完全一致 → 假设成立，继续完善
  ├── 部分一致 → 提取有用部分，修正假设
  ├── 完全不一致 → 假设错误，换新方向
  └── 不确定 → 设计更精确的实验
    ↓
还没找到答案？
  ├── 是 → 回到"提出假设"
  └── 否 → 结束
```

---

## 关键概念

### 假设（Hypothesis）

不是完整的答案，而是一个**可验证的猜想**。

❌ 不好的假设：
  "答案应该是 42"
  （无法验证为什么）

✅ 好的假设：
  "系统应该是阻尼谐振子，振幅指数衰减"
  （可以通过数值模拟验证）

### 实验（Experiment）

不是真正的物理实验，而是**验证假设的计算或推导**。

例子：
- 数值求解微分方程，看结果是否符合假设
- 做量级估算，检查假设是否合理
- 验证极限情况，看假设是否自洽

### 评估（Assessment）

对实验结果的分析，决定下一步方向。

三种可能的判断：
- **有希望** → 继续细化当前方向
- **死胡同** → 放弃当前方向，换新的
- **部分成功** → 提取有用的部分，修正后继续

---

## 关键决策点

### 决策 1：什么时候继续，什么时候放弃？

**继续的信号：**
- 量级估算正确
- 物理图像合理
- 与已知极限情况一致
- 只差一个小的修正项

**放弃的信号：**
- 量纲不一致，且无法修正
- 违反基本守恒律
- 连续 3 次尝试都失败
- 方向明显与物理直觉相悖

### 决策 2：如何避免无限循环？

**保护措施：**
- 设置最大迭代次数（如 5 次）
- 记录每次尝试，避免重复相同错误
- 如果连续 2 次在同一方向失败，强制换方向

### 决策 3：部分成功时怎么处理？

**提取有用部分：**
```
迭代 1：谐振子模型 → 频率正确，但没有衰减
  → 提取：振动频率 ω₀

迭代 2：加入线性阻尼 → 短期正确，长期偏差
  → 提取：阻尼系数 γ

迭代 3：加入非线性阻尼 → 完全正确
  → 成功
```

**原则：** 每次迭代都应该学到东西，即使整体失败

## 什么时候用 Iterative

✅ **适合的场景：**
- 开放性问题，没有标准答案
- 需要实验验证的问题（如：拟合实验数据）
- 逐步建模的问题（如：从简单模型开始，逐步加入修正）
- 参数不确定的问题（如：需要通过拟合确定参数）

❌ **不适合的场景：**
- 有明确标准解法的问题（用 Standard 更快）
- 需要精确答案的问题（迭代可能只得到近似）
- 时间紧迫的问题（迭代次数不可控）

---

## 与其他 Pipeline 的关系

**vs Standard：**
- Standard：一次性给出答案，最多修正一次
- Iterative：多次尝试，逐步逼近

**vs Tree Search：**
- Iterative：一条路走到底，走不通才换
- Tree Search：同时考虑多个分支，有策略地选择

**什么时候选 Iterative，什么时候选 Tree Search？**
- 如果你有一个大致方向，需要细化 → Iterative
- 如果你完全不知道方向 → Tree Search

## 实际例子

**问题：** 拟合实验测量的振动曲线

**迭代 1：**
- 假设：简谐振子
- 实验：求解 $m\ddot{x} + kx = 0$
- 结果：振幅不衰减，与实验不符
- 评估：**部分成功** — 频率正确，但缺少阻尼
- 学到：需要考虑能量耗散

**迭代 2：**
- 假设：阻尼谐振子，$F_{damping} = -\gamma \dot{x}$
- 实验：求解 $m\ddot{x} + \gamma \dot{x} + kx = 0$
- 结果：前 3 个周期吻合，后期偏差
- 评估：**部分成功** — 短期正确，长期有问题
- 学到：阻尼可能不是线性的

**迭代 3：**
- 假设：非线性阻尼，$F_{damping} = -\gamma \dot{x}^2$
- 实验：数值求解非线性方程
- 结果：完全吻合
- 评估：**成功**
- 最终答案：$m\ddot{x} + \gamma \dot{x}^2 + kx = 0$

## 核心优势

1. **灵活适应** — 根据反馈动态调整，不死板
2. **保留历史** — 每次尝试都有记录，可追溯
3. **逐步逼近** — 不需要一次性猜对
4. **学习过程** — 每次迭代都能学到东西

## 主要代价

1. **迭代次数不可控** — 可能很快成功，也可能很久
2. **需要好的判断力** — 什么时候继续、什么时候放弃
3. **可能陷入局部最优** — 需要强制换方向的机制
